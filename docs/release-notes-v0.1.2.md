# CarGPS 车机版 v0.1.2

面向 Android 8.1 及以上、1024×600 横屏车机。本版仅发布车机应用。

## 界面

- 重做驾驶主屏：瞬时速度最大，时分秒突出显示，年月日独立分色。
- 修复顶部指标被裁切的问题，数字随实际可用空间缩放，适配系统栏和放大字体。
- GPS、北斗卫星数量及 HDOP/PDOP/VDOP 集中到“定位详情”，保留常用指标与单位写法。
- 优化日夜配色与触控区域；定位关闭时可直接打开系统设置，仪表可见时保持屏幕常亮。

## 定位与性能

- 行程统计改为增量累计，避免长行程每秒扫描全部轨迹；时钟仅在界面可见时刷新。
- 修复暂停、恢复、失锁和前后台切换时的路段连接与移动时长累计问题；路段边界可随行程恢复。
- 分别显示 GPS 与北斗卫星数量，避免近期系统卫星总数被单个 NMEA 报文覆盖。
- DOP 与卫星计数按字段独立过期，避免旧数据一直显示为实时值。

## 验证

- 40 项本地测试通过，包括 API 27/28 下的界面和定位回归测试。
- 界面覆盖 1024×528 可用内容区、日夜主题与 1.0/1.3 倍字体。
- Release 构建、Lint 与 APK 签名验证通过。
- 尚未在真实车机上安装或路测；GNSS 驱动上报与实际系统栏仍需目标设备验证。
