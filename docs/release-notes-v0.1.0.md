# CarGPS v0.1.0

此版本最初在拆分前以双端形式发布。本文仅保留当前车机项目对应的 Android 8.1 / API 27 车机版记录。

## 车机版

- 针对 `CASKA_1024x600` 的横屏大字号仪表布局。
- 年月日时分秒在右上角同一行完整显示。
- 展示瞬时速度、行程里程、平均速度、最高速度、定位状态和卫星信息。
- 支持开始、暂停、继续和二次确认结束行程。

## 核心能力

- 最低支持 Android 8.1 / API 27，不依赖 Google Play Services。
- 使用系统 `LocationManager`、GNSS 和 NMEA 数据完成定位与诊断。
- SQLite 本地保存活动行程、暂停状态、历史统计和轨迹点。
- 应用进程被终止后可以恢复活动行程，并断开恢复前后的定位点，避免补算跨进程位移。
- SQLite 写入使用后台单线程有序队列，避免阻塞 GPS 主线程回调。

## 安装包

- `CarGPS-Car-v0.1.0.apk`：车机版，包名 `com.cargps`。
