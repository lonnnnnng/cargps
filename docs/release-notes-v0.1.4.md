# GPS 车机版 v0.1.4

Release 构建启用 R8 代码优化与资源压缩，移除未使用的 Material 图标和依赖代码，缩小安装包约 **91.5%**。

## 安装包对比

| 版本 | APK 大小 |
| --- | ---: |
| v0.1.3 | 10,737,789 字节（10.24 MiB） |
| v0.1.4 | 912,473 字节（0.87 MiB） |

原包中约 95% 是 DEX 代码；启用优化后未引用的图标与依赖实现被移除。保留 32/64 位 ARM、x86、x86_64 四种 ABI。应用名 `GPS`、包名 `com.lonng.cargps`，最低 Android 8.1（API 27）；版本代码为 `5`。

## 验证

- 40 项本地回归测试通过，包括 API 27/28 的离线界面测试；这些测试不执行 R8 压缩后的 APK。
- Release 构建、Lint 和专用发布证书验签通过。
- 静态 DEX 核对确认启动 Activity、Compose 界面、定位回调及 SQLite 路径保留。
- 未在真实车机运行压缩后的 APK，定位与道路表现仍需硬件验收。
- R8 映射与压缩报告按版本保存在本机，供崩溃堆栈还原使用。
