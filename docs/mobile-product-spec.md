# CarGPS 手机版产品规格

作者：long

最低运行环境：Android 8.1 / API 27

首轮验证设备：Pixel_9 模拟器

## 1. 产品定位

手机版用于步行、骑行、驾车或临时测速时随手查看定位与当前行程。它复用车机版的定位质量、速度和统计口径，但不把 1024×600 横屏界面缩放到竖屏。

## 2. 首屏信息层级

1. 顶部在一行完整显示年月日时分秒，并提供日夜模式切换。
2. 定位健康条同时显示文字状态、卫星使用数与定位精度；状态含义不能只依赖颜色。
3. 瞬时速度是首屏视觉中心，单位始终可见。
4. 当前行程卡片显示记录状态、里程、总时长、移动时长和停车时长。
5. 行程平均、移动平均、最高速度和海拔使用 2×2 统计卡片。
6. 经纬度、样本年龄、PDOP/HDOP/VDOP 和 NMEA 类型默认折叠，按需展开。
7. 最近行程以卡片方式展示最近 3 条本地记录，包含开始时间、时长和里程。
8. 底部固定唯一主操作；行程进行中才显示结束按钮，结束必须二次确认。

## 3. 交互与视觉约束

- 全部触控目标不小于 48 dp，主要按钮高度 58 dp。
- 页面只纵向滚动，不使用横向滑动和嵌套滚动。
- 固定底栏为滚动内容预留底部空间，系统状态栏和导航栏存在时不遮挡操作。
- 数字使用等宽字体，避免时间、速度和统计刷新时发生布局跳动。
- 夜间使用低眩光深色背景；橙色表达主要操作，绿色表达正常节奏或里程，不以颜色作为唯一状态提示。
- 定位过期时冻结统计并把速度归零；定位丢失时显示 `--`。

## 4. 模块与安装边界

- 手机包名固定为 `com.cargps.mobile`，可与车机包名 `com.cargps` 同时安装。
- `minSdk = 27`，不得引入仅在更高 API 可直接调用的定位重载。
- 首轮安装和视觉验收只使用 `Pixel_9` AVD，不能误装到已连接的 Redmi 真机。
- 活动行程和已结束行程使用本地 SQLite；进程重建后恢复时必须明确显示“已恢复上次行程”。
